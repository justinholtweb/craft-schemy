# Plugin Store promo images

Marketing images for the Schemy listing on the Craft Plugin Store, rendered in the same theme as the
plugin's marketing page at
[justinholt.com/plugins/craft-schemy](https://justinholt.com/plugins/craft-schemy).

## Building

```bash
./build.sh          # all slides
./build.sh "2 5"    # just slides 2 and 5
```

Output lands in `out/` as `schemy-promo-N.jpg`, 1920×1080 (rendered at 2× in headless Chrome, then
downsampled so the type stays crisp). **Promos are JPEG, never PNG** — Chrome can only write PNG, so
`build.sh` converts with `sips` at quality 90 and deletes the intermediate.

## Slides

| # | Slide | Shows |
|---|-------|-------|
| 1 | Cover — name, tagline, app icon, price | — |
| 2 | Structured data, and nothing else | what an SEO suite adds, and the one row Schemy shares with it |
| 3 | Fields in, a linked graph out | four property mappings and the JSON-LD they produce |
| 4 | Set it once, change it where it differs | section → entry type → entry, and the three merge rules |
| 5 | Pick a type, map its fields | **real** screenshot of a section's mappings |
| 6 | One entry, its own headline | **real** screenshot of the Schemy field, customized, with the preview |
| 7 | Automatic, until you want it not to be | auto-injection, `craft.schemy`, safe output, nothing extra |

Slide 4's merge rules have to agree with `services\Schema::getDocument()`: an entry override with the
same type layers onto the inherited properties, a different type starts fresh, and Disable drops
only the entry's own node (identity, WebSite and breadcrumbs stay). Change the merge and change the slide.

## Palette

Accent `#5B4FD9` from the icon's plate, `#A69DF6` as the light accent for anything small on the dark
background (the plate colour is too dark to read as text there), and the family's `#ffd166` gold.
Jersey 20 for display, Inter for body.

## The watermark is one brace

`assets/watermark.svg` is **not** `../src/icon-mask.svg`. The plate is stripped as everywhere in the
family, and so are the left brace and the graph: at watermark scale the three nodes read as grey
blobs, and a pair of braces frames the headline like a UI box. A single right brace, anchored
right and running off the edge, still reads as JSON. It is switched off on the cover.

`assets/icon.svg` is a straight copy of `../src/icon.svg`. Re-copy it whenever the icon changes.

## Screenshots

`shots/` holds crops of two of the marketing page's screenshots
(`~/Sites/justinholt/web/images/plugins/screenshots/craft-schemy/`, 2548px wide at 2×):

- `schemy-section.png` — `schemy-section.png`, cropped to the type and property rows
- `schemy-entry.png` — `schemy-entry.png`, cropped to the field and the top of the preview

Cropped with `sips --cropToHeightWidth H W --cropOffset Y X`. Note that an offset of `0 0` is
ignored and gives a *centred* crop; `1 1` crops from the top.

`fonts.css` is generated by `build.sh` and gitignored; don't edit it.
