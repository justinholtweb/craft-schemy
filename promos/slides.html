How it works

Fields in,
a linked
graph out

Map a property to a field you already have. Schemy shapes each value for the property it fills.

  • Assets become ImageObjects
  • Every node linked by @id
headline←Title datePublished←Post Date image←Featured image author←Byline
{ "@type": "NewsArticle", "headline": "Harbour terminal cuts berth waits", "datePublished": "2026-08-24T06:07:02-07:00", "image": { "@type": "ImageObject", "width": 1600, … }, "author": { "@type": "Person", "name": "Marta Okonkwo" }, "publisher": { "@id": "https://example.com/#identity" } }
